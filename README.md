# Linkcast

캡처보드로 입력되는 1080p 60fps 영상을 WebRTC P2P로 1~2명에게 초저지연 공유하는 웹 서비스입니다.

## 현재 구현

- 캡처보드 영상 입력 및 로컬 미리보기
- 실제 입력 해상도와 프레임 표시
- 송출 링크 생성과 복사
- 링크 또는 방 코드 참가 화면
- 데스크톱과 모바일 반응형 UI

현재 버전은 사이트와 캡처 입력 흐름을 구현한 단계입니다. 원격 영상 연결에는 WebSocket 시그널링 서버가 추가로 필요합니다.

## 실행

```bash
npm install
npm run dev
```

프로덕션 빌드는 `npm run build`로 확인할 수 있습니다.
